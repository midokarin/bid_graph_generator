# 预览编辑锁与轻量确认

日期：2026-09-11。

## 交互

- 正式前端画布默认锁定；点击预览工具栏的小锁后才能编辑文字、拖动流程节点。应用修改、打开项目或切换版本后重新锁定。
- 解锁期间文字和坐标修改先暂存到画布，可连续操作。点击工具栏「确认」才显示右上角轻量气泡，无全屏遮罩；「继续编辑」或 Escape 关闭气泡并保留调整。
- 「确认并应用」将本次调整保存为一个完整版本；「取消编辑」恢复原版本，不创建版本。
- 待确认草稿参与离页提示；保存、导出、切换图种、历史、模板和重新生成等操作会提示先处理草稿，避免静默丢失。版本仍须手动保存到文件。
- 原有样式修改确认也改用气泡；其余文件、历史、导出等弹窗保持原功能。
