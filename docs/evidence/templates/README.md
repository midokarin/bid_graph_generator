# 标书场景模板扩展验收

日期：2026-09-11。

## 交付范围

由 4 套扩展为 10 套模板，流程图与甘特图各显示 8 套适用模板。按黑白打印、技术方案、实施交付、进度计划筛选。新增宋体直角粗框、文字字重、节点顶部/左侧强调、虚线边框、甘特空心/斜线横道和隔行底纹。

模板仅调整全图样式，不修改文字、节点形状语义、位置、连线、依赖或工期。应用前展示样式差异；确认创建新版本，取消不创建版本。生成前选定的模板名称与外观一同写入快照。

新增 Style 字段为有默认值的可选字段，旧 1.0 项目继续按原外观显示，未知枚举仍被拒绝。保存及 PNG/SVG 导出复用相同快照和 Diagram。字体沿用本机字体回退规则，不保证缺少宋体/黑体的设备呈现同名字体。

本次保留现有主工作台布局与 Demo 文件；截图中的左侧版式交互由同一工作区的另一项任务修改，本次没有覆盖或提交该任务的改动。

## 验证

- `npm run quality`：后端 27 项、本次独立改动前端 80 项（合入并行任务后 84 项）、类型检查和生产构建通过；包含全模板业务/布局不变、版本快照、旧字段默认值、严格枚举和 SVG 效果验证。
- Chrome 真实浏览器 + 本机独立替身后端：模板筛选，流程图选择后取消/确认、顶部/左侧/虚线效果，甘特图生成前选择、纹理/隔行底纹、版本变化和工期不变。无页面异常，见 `browser-check.json`。
- 1440×900、1920×1080、390×844 视口，DPR 1；保存整页截图，因此文件高度可能超过视口。检查模板标签、卡片、筛选和手机宽度无横向溢出。未据此声称完成所有 Demo 页面逐像素对照。
- 两图种均通过界面下载实际 PNG、SVG 和项目 JSON，再在新页面使用文件上传入口重开；全部版本、样式和布局一致，重开后无未保存状态。PNG 均为 2480×3508，已人工查看。使用的是受支持的下载/上传文件适配器，不是原生覆盖保存。见 `file-check.json` 与输出文件。
- 本次不调用真实外部模型；验证数据来自现有替身样例。没有进行 Word/WPS 实机插入验收。
