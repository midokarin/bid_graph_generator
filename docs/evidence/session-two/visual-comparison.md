逐图视觉检查结论：导航、顶部操作入口、三步流程、三列分区及宽度、标题/控件字体、边距、配色、边框、圆角、模板卡片和历史弹窗没有发现未经授权的设计改动。默认字号曾错误采用合成项目的 16 磅，已修为 Demo 的 12 磅并重录正式截图。保留的基线没有改动。

允许差异分开说明：

- 按主规格替换“演示”等文案：本机替身状态、内存未保存提示、真实运行耗时及会话边界。数据和模板缩略图来源已改为当前 SVG。
- 流程图由 ELK 确定坐标和正交折点，包含文档、子流程和回路；图形随数据增长，可在原画布容器滚动。字号参数、字体、线色、圆角、箭头风格沿用 Demo。菱形和文档轮廓的边连接已经修复复验。
- 甘特由原三行固定示例改为五行真实排期，显示并行、提前/延迟和两个里程碑，时间刻度与画布高度由结果决定。图题仍独立于 SVG 业务结构。
- 方向选择位于原生成区，新增重新布局图标在预览工具区，AI 补充在原徽章区，透明背景在原样式区；全部使用既有控件风格，不改变主分区。方向选择占用生成区内一行，输入区仍按原规则滚动。
- JSON 输出位于原运行窗口，首次与修复分次展开：[截图](after/json-stream.png)。
- 历史不再受 Demo 的 8 版裁剪限制；选中历史再恢复成新版本。历史卡片尺寸、缩略图、选中样式和按钮位置不变。
- 本会话边界排除正式导出；原下载入口保留并显示同源 SVG 预览，下载按钮禁用。弹窗随真实图高度使用原有 max-height 和滚动规则，文案如实说明未提供文件下载。会话三再验收正式导出选项。

本记录证明当前环境下的界面复用与视觉检查，不声称跨平台像素一致或正式导出验收完成。截图哈希见 [manifest.json](manifest.json)；自动测试通过与视觉复核分别记录。
