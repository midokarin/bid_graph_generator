# 预览缩放修复验证

- 原因：缩放按钮修改宽度百分比，但固定最大宽度仍限制画布。在 1920×1080 浏览器中，100% 和 110% 实测均为 610px。
- 修复：最小/最大宽度随缩放倍率同步变化；使用自动外边距居中，超宽时从左侧开始，避免居中溢出使左侧无法滚动访问。
- Chrome 浏览器使用本地契约示例，未调用外部模型。流程图和甘特图均覆盖 1440×900、1920×1080、390×900。
- 验证实际图表宽度随 110%、150% 增长，60% 缩小、上下限按钮禁用、恢复适配、左右边缘滚动可达，版本/内容/未保存状态不变，无页面脚本错误。
- 1920px 视口下，100% 为 610px，110% 为 671px；1440px 视口下从 590px 增至 649px。
- `npm run quality` 通过：后端测试、契约检查、前端 85 项测试、类型检查和生产构建。
- `scripts/verify-preview-zoom.mjs` 可复验；`BIAOSHU_WEB_URL` 指定本地页面，`PLAYWRIGHT_MODULE` 指定 Playwright 模块。截图为 150% 状态，溢出内容在预览区域内滚动查看。
