- 系统文件选择器打开、首次保存、覆盖原文件、另存为；单个可读 JSON 保存原文、当前选择、全部快照、布局、样式及导出设置。打开直接使用保存的布局，不调用 ELK。没有自动保存、localStorage/IndexedDB 项目副本或恢复文件。
- 脏状态覆盖版本、原文和纸面等修改；写入和关闭成功后才标记已保存，失败或取消保留状态。打开其他项目前提示；页面关闭使用浏览器原生未保存提示。各图种保留各自历史、选择和脏状态。
- 显式 0.9 → 1.0 兼容迁移，保留快照并提示另存为；未来和未知版本拒绝。0.9 是本次明确的兼容测试格式：与 1.0 核心字段相同，仅版本不同且可缺少 metadata；没有已发布的 0.9 程序，也不支持猜测转换任意 Demo 文件。
- A4/A3、横竖向、可选图题、白色/透明/自定义背景；输出纸面包装和弹窗共用 `ExportSheet`，图形复用工作台 `Diagram` 与布局快照。PNG 由浏览器 SVG→Canvas 生成；SVG 无项目 JSON、原文、模型响应或编辑控件。长图保持单张，不分页。
- 模型设置弹窗、用户配置目录中的原子配置保存、Key 遮盖；无配置文件时读环境变量，已有用户配置优先。配置和项目文件分离。模型配置保存期间拒绝切换正在运行的任务配置。
