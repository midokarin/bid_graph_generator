# 甘特图长任务名误报修复

默认字号 12 在甘特图中按 16.8 SVG 单位显示。原实现固定每行 12 字，可读性检查却限定任务名宽度为 190，导致 12 字及以上的普通任务名被按 `12 × 16.8 = 201.6 > 190` 拦截。显式换行也会被错误地按总字数计算宽度。后端结构校验和排期成功后，前端因此无法创建版本。

修复将甘特任务文字的列宽、行高上限、字号比例和行距集中在 `frontend/src/layout/gantt.ts`，按字号与可用列宽计算每行容量。可读性检查、预览和 PNG/SVG 导出共用相同换行结果；保持字号、任务内容、排期、行位置、画布尺寸和依赖不变。超过 60 字或换行后超出可用行高的内容仍被拒绝。

## 验证结果（2026-09-11）

- 回归测试先在旧代码复现两项失败，修复后全部通过；覆盖正常长任务名、显式换行、字号变化和真正不可读的边界。
- `npm run quality` 通过：27 项后端测试、92 项前端测试、契约一致性、类型检查和生产构建。
- `scripts/verify-gantt-text.mjs` 使用合成 SSE 结果和实际 Python 排期，完成 11 项任务、2 个里程碑、61 天样例的生成与版本创建；未调用真实模型，未保存用户完整原文或模型响应。
- Chrome 153.0.8010.36、设备像素比 1，在 1440×900 和 1920×1080 视口截图检查。实际 SVG 文字边界验证通过，字号 12 和 16 均不越过任务名称列或相邻行。
- 实际导出 2700×3972 PNG 与 SVG，预览和导出任务文字/换行完全一致；视觉复核 PNG 确认任务及里程碑完整显示。
- 样式变更创建第二个版本；项目序列化后重载保留版本和排期。浏览器无页面异常。

## 复验

先启动正式前端：

```sh
npm run dev --workspace frontend -- --port 5191 --strictPort
```

再运行浏览器验证（需要 Playwright 和本机 Chrome）：

```sh
node scripts/verify-gantt-text.mjs
```

可通过 `BIAOSHU_WEB_URL` 指定开发服务、`PLAYWRIGHT_MODULE` 指定已有 Playwright 模块、`BIAOSHU_EVIDENCE_DIR` 指定输出目录。截图、导出图片及检查结果默认写入被 Git 忽略的 `tmp/gantt-text/`。

本次验证针对渲染错误；不代表已复跑用户当次真实模型输出或完成跨平台字体验收。
