# P0 开工文档

本文件用于直接向开发 Agent 交代任务。完整需求以 [`agent-development-spec.md`](./agent-development-spec.md) 为准。

## 使用方法

1. 第一次开发对话复制“会话一”任务。
2. 会话一完成并确认后，再分别复制会话二、会话三。
3. 每次只执行当前会话，不自动进入下一次。

---

## 会话一开工任务

请在 `/Users/wyx/编程/biaoshu2` 开始 P0 第一次开发会话：**正式骨架、数据契约与生成后端**。

开始前必须完整阅读：

- `AGENTS.md`
- `docs/agent-development-spec.md`
- 当前 Git 状态和现有 Demo 源码

本次目标：建立可启动的 React/FastAPI 正式工程，完成流程图与甘特图严格数据契约，并让替身模型通过 SSE 生成经过校验的 JSON。

必须完成：

1. 正式前后端目录、启动入口、统一质量命令和安全 `.gitignore`。
2. Pydantic 权威模型、JSON Schema、TypeScript 类型、项目文件与版本快照结构，以及两图种有效/无效样例。
3. 可配置 OpenAI 兼容适配器、两套提示词、任务创建、SSE、取消、有限 JSON 清理、严格校验和最多两次修复。

最小验收：

- 一条质量命令通过后端测试、前端类型检查和构建。
- 两图种契约在 Python 与 TypeScript 中保持一致，悬空引用和甘特依赖环会被拒绝。
- API 测试覆盖成功、一次修复成功和取消后不产出结果。

边界：保留 Demo 和人工修改；不得执行模型代码；不得把替身测试称为真实模型或浏览器验收；不得实现会话二、三的功能。

完成后提交 Git，并汇报：改动范围、验证结果、提交号、未完成项和下一会话的前置条件。然后停止。

## 会话二开工任务

请在 `/Users/wyx/编程/biaoshu2` 开始 P0 第二次开发会话：**双图渲染、工作台编辑与版本链路**。

开始前必须完整阅读 `AGENTS.md` 和 `docs/agent-development-spec.md`，检查 Git 状态，并确认会话一已经完成且验证通过；若前置条件不成立，先报告，不得假装完成。

本次目标：把已校验 JSON 变成可见、可编辑、可追溯的流程图和甘特图。

必须完成：

1. 接入 SSE 阶段状态和可展开 JSON 流窗口。
2. 使用 ELK.js Web Worker 完成流程图布局、六类节点、多分支、整改回路、拖动、重新布局和布局快照。
3. 使用 Python 完成甘特确定性排期，使用 React/SVG 绘制日/周/月、并行任务、提前/延迟和多里程碑。
4. 完成文字编辑、全局样式、模板、AI 补充标志、完整快照版本、历史查看和恢复。

最小验收：

- 两图种各一个样例完成“JSON → 布局/排期 → SVG”。
- 相同甘特输入得到相同排期；流程布局快照重载后坐标和折点不变。
- 一条浏览器主路径完成生成、编辑、创建新版本和恢复旧版本；质量命令通过。

边界：只使用替身模型即可；不得提前实现节点/连线增删、依赖编辑、自然语言二次修改、项目文件或正式导出闭环。

完成后提交 Git，并汇报：改动范围、自动验证、浏览器验证、提交号、未完成项和下一会话的前置条件。然后停止。

## 会话三开工任务

请在 `/Users/wyx/编程/biaoshu2` 开始 P0 第三次开发会话：**文件与导出闭环、真实模型和集成准备**。

开始前必须完整阅读 `AGENTS.md` 和 `docs/agent-development-spec.md`，检查 Git 状态，并确认前两次会话已经完成且验证通过。

本次目标：补齐个人本地程序的交付闭环，并用真实模型和真实浏览器完成 P0 总验收。

必须完成：

1. 项目打开、保存、覆盖、另存为、旧版迁移、未来版本拒绝和未保存提示；不增加自动保存或恢复副本。
2. A4/A3、横竖向、图题选项、白色/透明/自定义背景，以及与预览同源的 PNG/SVG 导出。
3. 设置页、用户配置目录、`127.0.0.1` 限制、临时日志清理、跨平台路径适配和独立模式 host adapter。
4. 使用真实 OpenAI 兼容模型分别生成一张流程图和一张甘特图，在真实 Chrome 或 Edge 中完成生成、编辑、导出、保存和重开。

最小验收：

- 统一质量命令全部通过。
- 两张真实模型图完成“生成 → 编辑 → PNG/SVG → 保存 → 关闭 → 重开”。
- 验证取消不创建版本、保存失败不清除未保存状态、未来版本文件被拒绝、服务只监听回环地址。

边界：不能把替身、静态测试或服务启动当作真实模型和浏览器闭环；当前机器无法验证的平台必须明确标为未验证。不得把密钥或完整临时日志提交到 Git。

完成后提交 Git，并汇报：P0 已完成能力、真实验收证据、未验证项、提交号和是否满足 `docs/agent-development-spec.md` 第 13 节。然后停止。
