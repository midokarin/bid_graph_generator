# 实时运行日志改进

本次按用户提供的参考图局部调整正式前端运行详情，沿用工作台的配色、三列日志和折叠状态栏。Demo、业务契约与图表布局未改动。

- 日志区显示实际事件耗时、程序 / LLM / 渲染器标签、阶段说明及成功或错误状态；生成中持续计时，结束后固定耗时。
- 首次生成与每次修复的 JSON 分别默认折叠，展开后可滚动查看；未完成时显示收到的流式文本，完整 JSON 自动缩进。格式化仅影响查看，不改变原始输出或业务数据。
- 错误使用可读说明，结构化技术详情单独折叠。上翻旧日志时暂停自动跟随，回到底部后继续跟随。
- 取消显示“已取消运行”，保留本次已收到的输出供查看，不创建新版本。

`npm run quality` 通过：21 项后端测试、75 项前端测试、契约同步检查、TypeScript 检查与生产构建。

macOS / Headless Chrome 153 浏览器检查采用独立本地替身服务，仅使用仓库合成样例，没有调用外部模型：

- 流程图生成成功，日志包含三类来源；JSON 默认折叠，点击展开后可解析且有缩进；甘特图正确显示 3 项普通任务、2 个里程碑，并记录排期步骤。
