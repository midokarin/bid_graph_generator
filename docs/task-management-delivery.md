# 简单任务管理

任务列表每一行右侧新增「…」，展开后可以：

- 重命名：就地编辑名称，去除首尾空格、拒绝空名称、最多 80 字符；支持取消编辑。名称独立于图表标题，重命名不创建图表版本，保存项目时写入 `metadata.task_name` 并遵守原有未保存提示。
- 取消生成：运行中的任务显示该入口，可直接取消后台任务而不切换工作台。保留输入和此前版本，迟到结果不创建版本。
- 删除任务：弹出包含任务名称、运行和未保存状态的确认提示。确认后取消生成并移除任务及页面中的历史，保留磁盘上已保存的项目文件；取消确认不作修改。

删除后台任务不改变当前任务；删除当前任务时选择相邻任务。删除最后一个任务时创建全新的空白任务。文件写入等不可取消的本地操作进行期间暂时禁用删除。任务列表仍是当前页面内存状态，不增加自动保存。

控制器以任务 ID 注册，删除和取消均定向调用对应控制器；卸载时终止本地流并发送后端取消，清理注册。即使创建请求尚未返回，删除后的迟到 job ID 也会走取消流程。重新布局在被终止后不会追加版本。
