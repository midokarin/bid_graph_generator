# 图题摘要与预览编辑

日期：2026-09-11。

- 两种图表共用图题要求：识别业务对象、核心工作与覆盖范围，再概括为简洁图题；通常 8–24 个汉字，优先沿用准确的原文图题，避免通用名称、步骤堆砌和虚构信息。图题与图表说明分别生成。
- 输入区图题改为选填，默认及载入示例时留空，避免示例标题覆盖 LLM 返回值；用户主动填写的标题仍优先用于此次生成。
- 生成后点击预览右上角小锁，再点击标题编辑。Enter 或失焦暂存；Escape 放弃本次输入；空白标题提示并保留原值。中文输入法选词时 Enter 不提前提交。
- 沿用画布草稿与确认流程：取消编辑恢复原值；确认并应用创建完整版本，旧版本保留；标题与节点文字可合并为同一次修改。预览显示草稿标题，版本记录、项目文件和 PNG/SVG 使用对应正式快照的标题。
- 标题长度使用现有契约的 200 字上限，无 Schema 变更；换行与连续空白规整为单行空格。
