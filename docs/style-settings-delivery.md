# 版式设置：实时试调与确认应用

本次按用户要求局部优化正式前端的版式设置，保留三栏工作台结构。

- 删除版式面板里的颜色、透明背景、目标纸型、页面方向和固定参数说明；纸面和背景输出选项仍在导出弹窗中。
- 字体、字号、线宽、圆角统一为实时试调；提供标准、醒目、柔和三种快捷组合。甘特图显示“进度条圆角”。
- 主预览切换“查看原版 / 返回调整效果”；可撤销全部试调，或恢复默认控件值。默认操作保留现有配色与模板的其他属性。
- 应用前不写入版本或项目文件。应用一次创建一个完整快照，项目仍须手动保存。原样调回时自动结束试调。
- 字号导致文字超出既有图形时提示并禁用应用；业务数据、布局和排期保持不变。
- 试调期间保存、导出、切换版本/图种、重新布局等操作引导先处理试调；关闭页面仍提示未确认修改。
- 1440px 下四项常用控件直接可见；小屏增加预览与设置之间的快捷跳转。

## 验证

- `npm run quality`：工作区后端 27 项、前端 84 项测试通过，契约检查、类型检查、生产构建通过。
- 仅本次暂存代码导出到独立目录后，统一质量检查再次通过：后端 26 项、前端 82 项；确认不依赖另一项模板扩展。
- 新增 4 项版式回归测试，覆盖试调隔离、确认快照、溢出阻止、原值恢复、两种图表的项目序列化与 SVG 结果。
- Chrome 自动化使用合成项目，验证即时效果、原版对比、撤销、跨操作保护、单次应用、实际 JSON 下载后上传重开、共用导出组件；未调用外部模型。
- 浏览器逐项结果见 `evidence/style-settings/browser-check.json`；复跑脚本 `scripts/verify-style-settings.mjs` 使用 Playwright 与本地正式前端，支持 `PLAYWRIGHT_MODULE` 和 `BIAOSHU_WEB_URL` 指定已有运行环境。
- 1440×900、1920×1080 截图分别保存原界面、相同数据的新版界面和两图种试调；390px 检查无横向溢出与快捷跳转。截图为完整页面，因此高度可能超过视口。
- 本机没有 agent-browser CLI，改用已有 Playwright 驱动真实 Chrome，实际检查页面加载、交互和页面异常；`pageErrors` 为空。
