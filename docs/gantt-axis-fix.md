# 甘特图时间轴小数刻度修复

原因：时间轴固定将总长度均分为六份。61 天因此显示为 10.17、20.33、30.5、40.67、50.83、61 天；这些是时间轴刻度，并不是任务工期。

处理：中间刻度取整数，并用实际刻度值计算横坐标。61 天显示为 0、10、20、31、41、51、61；不足六个单位的排期减少刻度数量，避免重复。准确终点保留，合法的小数业务数据不被取整。任务工期、排期、里程碑及保存的布局不变，预览和导出共用 Diagram 渲染。

验证：`npm run quality` 通过，包含契约一致性、后端测试、前端测试、类型检查和生产构建。新增回归测试覆盖 1–366 天、零长度、短工期、小数终点，以及根据报告日期手工构造的 61 天跨月排期 SVG。验证刻度文字与坐标一致，任务和里程碑不被修改。

本次未调用真实模型，未执行浏览器截图或 PNG 实际下载验收。该问题在本地渲染层修复；已有项目重新打开或刷新预览即可使用新刻度，无须重新调用模型。
