# 甘特图生成缺失任务修复

## 问题与处理

报告中的模型 JSON 已经只剩一个数字任务，图片忠实呈现了错误数据。现有结构校验只能确认字段类型、引用、数值和无环，无法证明模型完整理解原文。

本次接续工作区已有的生成 Schema 兼容修复：初次提示词、修复提示词和供应商 response_format 共用转换，移除自然语言字段的非空白搜索正则 `\S`，避免兼容接口将其按完整匹配解释而限制为单字。本地 Pydantic 非空白校验保持不变，带锚点的 ID 规则保留。

补强甘特图提示词：

- 完整保留明确任务、任务名、工期和里程碑。
- 第 1 天开始对应内部偏移 0；完成后立即开始使用 FS、lag=0。
- 完工时发生的零工期里程碑依赖前置任务，不使用工期数字充当最早开始位置。
- 总工期上限不转换为任务；无估算时补充信息为空。

保持现有 P0 边界：不使用关键词规则自动补造任务，不增加总工期冲突或业务覆盖率阻断。此修复不承诺任意模型输出都没有业务错误。
