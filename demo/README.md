# 标绘 · 本地交互 Demo

用于评审标书图表的界面与操作流程。无后端、模型调用或上传。采用 React、TypeScript、Vite、Zustand 与 SVG 演示画布，不代表 React Flow / ELK 或 Frappe Gantt 已完成适配。

## 运行和验证

在 `demo` 目录执行 `npm install`、`npm run dev`，打开终端显示的本地地址。

- `npm test`：版本、锁、编辑补丁、保存迁移、规则及渲染测试。
- `npm run build`：TypeScript 与生产构建。

## 当前操作流程

1. 选择流程图或甘特图，生成内置示例草稿。
2. 流程图双击文字或聚焦节点后按 Enter，在节点内输入新文字。Enter 提交，Escape 取消；随后核对修改差异并确认。
3. 拖动流程节点，连线跟随移动。松开后核对坐标差异，确认创建新版本；取消保留原位置。指针取消时也保留原位置。
4. 甘特图双击任务名称修改文字，保持工期及时间条位置不变，不开放拖条改期。
5. 在「版式设置」选择字体、文字色、线条色、节点填充、画布背景、线宽及普通节点圆角。颜色支持取色器和 HEX 色号。点击「查看并应用」核对差异；字号单独确认。
6. 预览工具栏的「业务内容保护」阻止节点/任务文字及工期修改，允许移动位置与调整样式。
7. 右侧选择经典黑白、商务蓝、简约绿或极简线框模板。未生成时更新示例预览；已生成时先核对样式差异再应用，保留节点、文字、工期。
8. 点击右上角「下载草稿 PNG」时会先自动检查当前版本，通过后显示实际输出预览；存在阻断时不会导出。顶部流程为「输入内容 → 预览与修改 → 检查与下载」；不会自动把待确认规则改成已确认。旧项目已有确认规则仍生效，冲突时保留阻断。
9. 手动保存到当前浏览器；「本地项目」重新打开；从左侧「版本记录」弹窗恢复上一版会创建新版本。旧版保存数据读取时补充默认样式和节点位置。
10. 预览栏下方的「运行详情」会在生成时流式显示当前步骤；展开后可查看程序、LLM 与渲染器的相对时间和完整消息。当前为前端模拟链路，不会向模型或后端发送数据。

底部「用一句话修改图表」入口已移除。Demo 新增直接编辑与自定义背景是用户本次指定的体验扩展，不修改正式 P0 DiagramSpec 或宣称正式产品已经具备高级编辑器能力。

## 边界

- 所有业务内容均为内置示例，不作为真实项目承诺。自定义业务文本不做伪识别，仍需载入内置示例。
- 独立 Snapshot 视图模型，不是完整 DiagramSpec 或后端 Schema。
- 连线跟随节点锚点，但没有避障路由、拖动新增连线、增删节点或完整 draw.io 编辑能力。
- 字体使用本机字体，未安装时浏览器可能回退。真实字体、文字物理尺寸、节点重叠/裁字、纸面适配、暗标及真实合规性仍未核验，只开放草稿输出。
- PNG 与预览共用图形数据和样式，导出移除选中框与输入框。宽 1890 px，建议插入 160 mm，约 300 DPI；不写入 DPI 元数据或图题。自定义背景实际进入 PNG。
- A4/A3 和方向记录在版本中，完整纸面适配未实现。
- 只手动保存一份项目历史至当前浏览器 localStorage。未生成输入和未应用的版式草稿不包含在保存范围；清理浏览器数据后无法恢复。
- 可选 WebMCP 检查工具复用界面检查。函数合同有测试，浏览器注册未验证。
